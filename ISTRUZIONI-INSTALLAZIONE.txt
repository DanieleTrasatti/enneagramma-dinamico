 IL VIAGGIO DELL'ESSERE — AGGIORNAMENTO v25
 Gadget bilingue IT/EN con bandierine (Google Translate)
================================================================================
COSA CONTIENE
  Il sito resta in ITALIANO (base: versione DT23). In alto a destra nel
  menu di OGNI pagina compare il selettore di lingua: bandierina 🇮🇹
  (torna all'italiano) e bandierina 🇬🇧 (apre la pagina tradotta in
  inglese da Google Translate). La traduzione avviene al volo sul sito
  pubblicato: nessun file inglese da mantenere.

FILE MODIFICATI rispetto alla v23 (caricare questi):
  - le 8 pagine HTML (selettore bandierine + script, ?v=25)
  - css/style.css (nuove regole .lang-switch) — caricare anche questo
  - ISTRUZIONI.txt, questo file, README.md

FILE AGGIUNTI: NESSUNO (il gadget e' interamente inline nelle pagine:
  markup delle bandierine + piccola funzione JavaScript switchLang()).

ISTRUZIONI
  1. Carica i file sopra elencati nelle rispettive posizioni
     (le pagine nella root, style.css dentro la cartella css/ minuscola).
  2. Apri il sito: in alto a destra nel menu compaiono 🇮🇹 e 🇬🇧.
  3. Clicca 🇬🇧: la pagina si apre tradotta da Google (prima traduzione
     piu' lenta, poi cacheata). Clicca 🇮🇹 per tornare all'italiano.
  4. Forza il refresh con Ctrl+F5.

NOTE PER GITHUB PAGES
  - Nessuna impostazione speciale: GitHub Pages serve il JavaScript
    inline come qualsiasi altro hosting.
  - Il proxy di traduzione funziona sia con indirizzi
    tuonome.github.io/enneagramma-sito sia con domini personalizzati.
  - Se un giorno sposti il sito su un altro dominio, il gadget
    funziona lo stesso (l'URL viene costruito dal nome dell'host).
